# Bacem El Manai — Portfolio

Cyberpunk / Blade Runner 2049–themed Jekyll portfolio for GitHub Pages.

## Setup

1. Push this to a repo named `becem69.github.io` (or any repo — enable Pages either way).
2. Settings → Pages → Source: branch `main`, folder `/root`.
3. Optional: drop your CV PDF at `assets/Bacem_El_Manai_CV.pdf` — the hero's "Download CV" button links there.
4. Add more projects: new markdown file in `_projects/`, following the existing frontmatter shape (`title`, `tagline`, `year`, `stack`, `repo`, `perms`, `risk`, `excerpt`, `order`).

## Local dev

```
bundle install
bundle exec jekyll serve
```

Visit http://localhost:4000
