- Intelligent service detection (SSH, HTTP, RDP, MySQL) with security recommendations
- Flexible port input: ranges, lists, presets — plus JSON export for reporting
- Robust error handling, DNS resolution, and a user-friendly `argparse` CLI
- 50+ GitHub stars, contributions from 5 community developers
